Supervisor is a desktop mod manager. This policy describes what data the app handles.

---

**No telemetry**: Supervisor does not send analytics or crash reports to Supervisor contributors.

**Local-first.** Mod libraries, loadouts, staging files, and settings are stored on your PC under your user profile (app data directory).

**Auto-updates**: When enabled, Supervisor checks GitHub Releases for new versions and downloads signed update packages from GitHub.

## Data locations (Windows)

Typical paths:

App data: `%APPDATA%\com.supervisor.app\`

Staging: `%APPDATA%\com.supervisor.app\staging\`

Themes: `%APPDATA%\com.supervisor.app\themes\`

## Third parties

**Nexus Mods**: mod metadata and downloads when you use Nexus integration

**GitHub**: application updates (if you use auto-update)

**Steam / Epic / GOG**: local registry and manifest reads for game detection only

## Contact

Open an issue on the [Repository](https://github.com/natcale/Supervisor) for privacy questions.
